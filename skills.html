Recommended workflow stages

Most projects move through the same five stages. Mention the right thing and Claude pulls the right skill — no manual switching.

Plan & spec

Lock context before you build. Write it down, ship a decision doc.

  • doc-coauthoring
  • internal-comms

Design & brand

Set the visual direction — colors, typography, theme, look-and-feel.

  • brand-guidelines
  • theme-factory
  • frontend-design

Build

Actually make the thing: site, app, API integration, or MCP server.

  • frontend-design
  • web-artifacts-builder
  • claude-api
  • mcp-builder

Package & deliver

Turn the work into the artifact your audience actually opens.

  • pptx · docx · pdf · xlsx
  • canvas-design
  • algorithmic-art
  • slack-gif-creator

Verify & iterate

Test what you built, then codify wins as reusable skills.

  • webapp-testing
  • skill-creator
Tip: Skills stack. A single prompt like "Build a landing page in our brand colors, export the pitch as a PPTX, and test the form in a headless browser" will load frontend-design + brand-guidelines + pptx + webapp-testing in one go.
